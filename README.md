# lecteur-de-nombre

Ce programme demande un nombre dans le terminal puis l'affiche.

## Fonctionnalités

- Pose une question à l'utilisateur dans le terminal avec `readline`
- Lit la réponse tapée au clavier
- Transforme le texte saisi en vrai nombre avec `Number()`
- Affiche le nombre obtenu

## Prérequis

- Node.js installé sur l'ordinateur

## Lancer le projet

```
npm install
node index.js
```



## Exemple

```
entrer un nombre:6
le nombre est: 6
```
